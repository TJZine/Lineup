# Quick Start

This is the shortest current path from launch to a working lineup.

## 1. Sign In to Plex

1. Launch **Lineup** on your TV.
2. Request a Plex PIN if one is not already shown.
3. On another device, visit [plex.tv/link](https://plex.tv/link).
4. Enter the PIN and complete the Plex sign-in flow.

## 2. Choose a Plex Server

1. Wait for Lineup to discover available servers.
2. Select the server you want to use for this TV.
3. Continue into setup once the connection succeeds.

## 3. Build Your First Lineup

On first run, Lineup opens the Channel Setup flow instead of dropping you into an empty app.

1. Pick the libraries you want included.
2. Keep the default strategy settings if you want the fastest path.
3. Select **Build Channels**.
4. Wait for the build to finish and for the guide data to refresh.

## 4. Start Watching

Once setup completes:

1. tune to a channel
2. use **CH+ / CH-** to surf
3. press **Guide** to open the EPG
4. return to **Channel Setup** later if you want to expand or reshape the lineup
