# Agent Eval Roadmap

Keep a small balanced suite covering:

- one isolated low-risk change that should remain single-agent;
- one normal feature or bug fix;
- one architecture/hotspot refactor;
- one Plex or persistence boundary change;
- one UI behavior requiring real runtime/manual proof;
- one review task containing a genuine defect and one clean task.

The next workflow comparison should test the simplified July 2026 harness against
the previous mandatory planner/reviewer pipelines. Compare outcome correctness,
escaped defects, rework, agent passes, wall time, required-reading bytes, and observed
token/cost data. Add scenarios only after a real failure exposes a missing dimension.
