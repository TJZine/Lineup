# Workflow Entry Points

Start with [AGENTS.md](../../../AGENTS.md) and the relevant sections of the
[workflow](../../AGENTIC_DEV_WORKFLOW.md). Describe the requested outcome directly;
feature and cleanup work use the same workflow without separate launcher skills.

Use the smallest matching process and boundary skills under `.agents/skills/`.
Planning, review, and multi-unit orchestration remain available when the task needs
them. Historical launcher names in old plans are reference material, not required
steps for current work.
