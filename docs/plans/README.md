# Active Plans

This directory is for durable cross-session plans, not routine task notes.

A plan is active only when its opening metadata declares active status. Follow
[`docs/agentic/plan-authoring-standard.md`](../agentic/plan-authoring-standard.md).
Use one plan per workstream, keep progress and decisions current, and mark or move it
to historical/reference context when complete.

Unmarked documents are reference material and do not control current work.
