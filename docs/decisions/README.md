# Architecture Decision Records (ADR)

This directory contains records of significant architectural decisions made for Lineup.

## What is an ADR?

An **Architecture Decision Record** captures a single AD, such as a choice of technology, a pattern, or a significant refactoring. It describes the context, the decision, and the consequences.

## Template

Use the following template for new ADRs:

```markdown
# [Short Title]

- **Status**: [Proposed | Accepted | Deprecated]
- **Date**: [YYYY-MM-DD]
- **Drivers**: [Business, technical, or organizational reasons that prompted this decision]

## Context

Describe the problem or situation.

## Decision

Describe the decision and the justification.

## Consequences

**Positive:**
- ...

**Negative:**
- ...
```
